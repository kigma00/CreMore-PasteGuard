# CreMore PasteGuard

**복사는 그대로 하고, 내가 정한 앱이나 웹사이트에 특정 글자를 붙여넣는 것만 막아요.**

예를 들어 Slack에 토큰을 실수로 붙여넣지 않도록 설정할 수 있어요. 여기서 **토큰**은 서비스에 들어갈 때 쓰는 비밀번호 같은 값이에요.

처음이라면 진짜 비밀번호 대신 **가짜 글자로 메모장에서 연습**해 보세요. 아래 순서대로 하면 돼요.

> Windows 앱에서는 `Ctrl+V` 또는 `Shift+Insert`로 붙여넣을 때 작동해요. Windows 앱의 마우스 오른쪽 버튼 메뉴로 붙여넣는 것은 막지 않아요.

## 앱 열기

Windows 10 또는 11에서 사용해요. .NET Framework 4.8이 필요해요. 별도 서버나 서비스 계정은 필요하지 않아요.

### 실행 파일을 받았다면

1. `CreMore-PasteGuard-windows.zip`을 받았다면 마우스 오른쪽 버튼을 누르고 **압축 풀기** 또는 **모두 추출**을 선택해요.
2. 압축을 푼 폴더를 열어요.
3. **CreMore PasteGuard.exe**를 두 번 눌러요.

**성공하면:** `차단 규칙`, `브라우저 연결`, `차단 기록` 탭이 있는 창이 열려요.

파일 하나만 꺼내지 말고 폴더 전체를 함께 두세요. 특히 `.exe.config` 파일과 `extension` 폴더를 지우지 마세요.

### GitHub에서 코드만 받았다면

**현재 GitHub Releases에는 실행용 ZIP이 올라와 있지 않아요.** GitHub의 **Code → Download ZIP**으로 받는 것은 소스 코드예요. 바로 실행할 수 있는 앱 파일은 들어 있지 않아요.

이 경우 아래 안내를 펼쳐 실행 파일을 한 번 만들어 주세요. 이미 앱이 열렸다면 건너뛰어도 돼요.

<details>
<summary>코드로 실행 파일 만들기</summary>

1. [저장소 첫 화면](https://github.com/kigma00/CreMore-PasteGuard)에서 **Code → Download ZIP**을 눌러요.
2. 받은 ZIP의 압축을 모두 풀어요.
3. 압축을 푼 폴더 안에서 **build.ps1** 파일이 보이는 폴더를 열어요.
4. 그 폴더의 파일 탐색기 주소창에 `powershell`을 입력하고 Enter를 눌러요.
5. 열린 PowerShell 창에 아래 한 줄을 붙여넣고 Enter를 눌러요.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

6. `Built:`라는 글자가 나오면 끝이에요. `dist` 폴더 안의 `PasteGuard` 폴더를 열어요.
7. **CreMore PasteGuard.exe**를 두 번 눌러요.

이 과정을 **빌드**라고 불러요. 소스 코드로 실행 파일을 만드는 일이에요. 오류가 나면 [빌드 참고](docs/technical-reference.md#빌드)를 확인하세요. 회사 PC에서 실행이 차단되면 관리자에게 확인하세요.

</details>

## 메모장에서 처음 시험하기

이번에는 **가짜 글자는 막히고, 평범한 문장은 들어가는지** 확인할 거예요. 인터넷에 글을 올리지 않아도 시험할 수 있어요.

### 1. 빈 메모장을 열어요

Windows의 **메모장**을 열고 새 문서를 만들어요. 아직 아무것도 입력하지 않아도 돼요.

### 2. PasteGuard에 규칙을 만들어요

**규칙**은 “어디에 어떤 글자를 붙여넣지 못하게 할지” 적어 두는 설정이에요.

PasteGuard의 **차단 규칙** 탭에서 아래처럼 입력해요. 이미 다른 규칙이 보이면 먼저 **+ 규칙 추가**를 눌러요.

| 화면의 항목 | 이렇게 입력하거나 선택해요 |
|---|---|
| 규칙 이름 | `메모장 연습` |
| 앱 실행 파일명 | `notepad.exe` |
| 웹사이트 도메인 | 비워 두세요 |
| 검사 패턴 아래 선택 상자 | **테스트 문자열** 선택 |
| 규칙 사용 | 체크 표시 켜기 |

**검사 패턴**은 막을 글자의 모양이에요. 처음에는 **테스트 문자열**을 고르면 돼요. 어려운 검사식을 직접 쓸 필요가 없어요.

입력칸의 흐린 회색 글자는 예시예요. 실제 값이 아니니 위 내용을 직접 입력해 주세요.

### 3. 앱 안에서 먼저 시험해요

아래 가짜 글자를 복사해요. 마우스로 글자를 선택한 뒤 `Ctrl` 키를 누른 채 `C`를 누르면 복사돼요.

```text
PGTEST_ABCD1234EFGH5678
```

PasteGuard 아래쪽 **테스트** 입력칸에 붙여넣고 **테스트** 버튼을 눌러요.

**성공하면:** `차단 조건에 해당해요`로 시작하는 결과가 보여요.

이 버튼은 검사만 해요. 아직 메모장 붙여넣기를 막기 시작한 것은 아니에요.

### 4. 저장하고 보호를 켜요

1. 아래쪽 **규칙 저장**을 눌러요.
2. 위쪽 **보호 시작**을 눌러요.
3. 위쪽 상태가 **Windows 보호 중**으로 바뀌었는지 확인해요.

### 5. 메모장에 붙여넣어 봐요

1. 위의 `PGTEST_ABCD1234EFGH5678`을 다시 복사해요.
2. 메모장의 빈 문서 안을 눌러요.
3. `Ctrl` 키를 누른 채 `V`를 눌러요.

**성공하면:** 가짜 글자가 메모장에 들어가지 않아요. PasteGuard의 **차단 기록** 탭에는 `notepad.exe`와 `메모장 연습` 기록이 생겨요.

이번에는 아래 평범한 문장을 복사해서 같은 방법으로 메모장에 붙여넣어 봐요.

```text
안녕하세요
```

**성공하면:** 이번 문장은 메모장에 들어가요. 복사 직후 검사 준비 때문에 잠깐 막혔다면 잠시 기다렸다가 다시 붙여넣어 보세요. 다른 규칙이 이 문장을 막고 있지 않은지도 확인하세요.

> 이 연습 규칙은 `PGTEST_`로 시작하는 정해진 모양의 글자만 막아요. 모든 비밀번호나 토큰을 자동으로 찾아주는 설정은 아니에요.

## Slack과 Notion 앱에 적용하기

메모장 시험을 마쳤다면 새 규칙을 만들어 원하는 앱에 적용해 보세요.

1. **+ 규칙 추가**를 눌러요.
2. 규칙 이름을 적어요. 예: `Slack 토큰 보호`.
3. **차단 대상**에서 **+ Slack** 또는 **+ Notion**을 눌러요. 필요한 앱 이름과 웹사이트 주소가 자동으로 들어가요.
4. **검사 패턴** 아래에서 막을 글자 종류를 골라요.
5. **규칙 사용**을 켜고 **규칙 저장**을 눌러요.
6. 위쪽 상태가 **Windows 보호 중**인지 확인해요. 꺼져 있으면 **보호 시작**을 눌러요.

| 검사 유형 | 언제 고르면 되나요? |
|---|---|
| 테스트 문자열 | 처음 연습할 때. 위의 가짜 글자로 시험해요. |
| GitHub PAT (classic) | `ghp_` 뒤에 영문과 숫자 36개가 붙는 토큰 형식을 막을 때 |
| 직접 입력 | 내가 정한 다른 글자 모양을 막을 때. [예시 보기](#직접-입력-예시) |

**Slack 앱과 Slack 웹사이트는 달라요.** 앱은 이 단계까지 설정하면 지원하는 단축키를 검사해요. Chrome이나 Edge에서 연 웹사이트는 아래 연결도 해야 해요.

## 웹사이트에도 적용하기

웹사이트 보호에는 **브라우저 확장 프로그램**이 필요해요. 브라우저 안에서 붙여넣기를 확인하는 작은 추가 프로그램이에요.

먼저 **+ 규칙 추가**를 누르고 규칙 이름을 적어요. **+ Slack** 또는 **+ Notion**을 누른 뒤 **테스트 문자열**을 고르고, **규칙 사용**을 켠 상태로 **규칙 저장**을 눌러요. 실제 토큰 대신 위의 가짜 글자로 시험해요.

### 1. 확장 프로그램을 넣어요

1. PasteGuard에서 **브라우저 연결 → 확장 폴더 열기**를 눌러요. 이 폴더의 위치를 확인해 두세요.
2. Chrome이면 주소창에 `chrome://extensions`, Edge이면 `edge://extensions`를 입력해요.
3. **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램 로드** 버튼을 눌러요. 브라우저에 따라 **압축 풀린 파일 로드**로 보일 수 있어요.
5. 1번에서 확인한 **extension 폴더**를 선택해요. 파일 하나나 앱의 상위 폴더를 고르는 것이 아니에요.

**성공하면:** 브라우저의 확장 목록에 **CreMore PasteGuard**가 나타나요.

### 2. 앱과 확장을 연결해요

1. PasteGuard에서 **연결 키 복사**를 눌러요.
2. 브라우저 오른쪽 위의 확장 프로그램 메뉴를 열고 **CreMore PasteGuard**를 눌러요.
3. **Windows 앱 연결 키** 칸에 붙여넣고 **연결**을 눌러요.

**연결 키**는 이 PC의 PasteGuard와 확장을 연결하는 값이에요. GitHub 토큰이나 다른 서비스의 비밀번호를 넣는 칸이 아니에요.

### 3. 규칙을 받아오고 확인해요

1. PasteGuard에서 규칙이 저장되어 있고 **Windows 보호 중**인지 확인해요.
2. **브라우저 확장 창**에서 **정책 새로고침**을 눌러요. 여기서 정책은 앱에 저장한 규칙과 보호 상태를 뜻해요.
3. **웹사이트 보호 사용 중**이 표시되고, **웹사이트 규칙**에 원하는 주소가 있는지 확인해요.
4. 보호할 Slack 또는 Notion 웹페이지를 새로고침해요.
5. 가짜 글자를 복사해서 입력칸에 붙여넣어 봐요. 메시지를 보내거나 페이지를 공유할 필요는 없어요.

**성공하면:** 글자가 붙여넣어지지 않고 페이지에 차단 안내가 나타나요.

앱의 **상태 새로고침**은 연결 상태를 보여주는 버튼이에요. 규칙을 바로 받아오는 버튼은 **확장 창의 정책 새로고침**이에요.

## 막을 글자 모양을 여러 개 넣기

한 규칙에서 여러 모양을 함께 막을 수 있어요.

1. 바꿀 규칙을 선택해요.
2. **+ 패턴 추가**를 눌러요.
3. 아래 선택 상자에서 검사 유형을 고르거나 **직접 입력**으로 새 조건을 적어요.
4. **규칙 저장**을 눌러요. 웹도 사용한다면 확장의 **정책 새로고침**을 눌러요.

예를 들어 **테스트 문자열**과 **GitHub PAT (classic)**을 넣으면 둘 중 **하나만 맞아도** 막아요.

기존 패턴을 선택한 채 유형을 바꾸면 그 패턴이 바뀌어요. 새 조건을 더하려면 먼저 **+ 패턴 추가**를 눌러 주세요. 빼려면 목록에서 고른 뒤 **선택 패턴 삭제**를 눌러요.

한 규칙에는 최대 16개, 전체 규칙을 합쳐 최대 100개 패턴을 넣을 수 있어요. 빈 패턴은 채우거나 삭제해야 저장돼요. **테스트** 버튼은 선택한 하나뿐 아니라 그 규칙에 있는 모든 패턴을 확인해요.

## 직접 입력 예시

이 부분은 다른 글자 모양을 직접 만들고 싶을 때만 읽어도 돼요.

예를 들어 `ghg_DEMO123`처럼 `ghg_`로 시작하고 영문이나 숫자가 이어지는 가짜 글자를 막으려면:

1. **검사 패턴**에서 **직접 입력**을 골라요.
2. 바로 아래 입력칸에 다음을 넣어요.

```text
ghg_[A-Za-z0-9]+
```

3. **테스트** 칸에 `ghg_DEMO123`을 넣고 **테스트**를 눌러요.
4. 결과를 확인하고 **규칙 저장**을 눌러요.

이런 글자 모양을 적는 방법을 **정규식**이라고 불러요. PasteGuard는 일부 문법만 지원해요. [지원하는 문법 확인하기](docs/technical-reference.md#직접-입력-패턴)

## 보호 끄기

**보호 중지**는 앱과 웹 모두에 적용돼요. Windows 앱에서는 바로 멈추고, 웹에서는 다음 자동 확인 때 멈춰요. 웹에도 바로 반영하려면 확장의 **정책 새로고침**을 눌러요.

| 끄고 싶은 곳 | 할 일 |
|---|---|
| 앱과 웹 보호 모두 | PasteGuard에서 **보호 중지**를 눌러요. |
| 웹 보호도 멈췄는지 바로 확인 | 중지 후 확장 창에서 **정책 새로고침**을 눌러요. **전체 보호 일시 중지**가 표시되는지 확인해요. |
| 브라우저 연결 자체 | 확장 창에서 **연결 해제**를 눌러요. 다시 사용하려면 연결 키로 연결해요. |
| 규칙 하나만 | 그 규칙의 **규칙 사용** 체크를 끄고 **규칙 저장**을 눌러요. 웹에는 정책 새로고침으로 반영해요. |

**앱을 닫는 것만으로 웹 보호까지 바로 꺼지지는 않아요.** 확장은 마지막으로 받은 규칙을 계속 사용할 수 있어요.

앱을 다시 열면 Windows 보호는 꺼진 상태로 시작해요. 다시 사용할 때 **보호 시작**을 눌러 주세요.

## 잘 안될 때

| 이런 일이 생겼나요? | 이렇게 확인해 보세요 |
|---|---|
| 입력칸에 예시가 있는데 저장이 안 돼요. | 회색 글자는 예시예요. 이름과 대상을 직접 입력했는지 확인하세요. |
| 앱 안의 테스트는 되는데 실제 붙여넣기가 돼요. | **규칙 저장 → 보호 시작**을 했는지 확인하세요. Windows 앱에서는 `Ctrl+V`로 시험하세요. |
| 메모장에서 안 막혀요. | 앱 실행 파일명이 `notepad.exe`인지, **규칙 사용**이 켜져 있는지, 가짜 글자를 정확히 복사했는지 확인하세요. |
| 웹에서 안 막혀요. | 확장 연결, 보호 상태, 웹사이트 규칙의 주소를 확인하고 **정책 새로고침** 후 웹페이지도 새로고침하세요. |
| 현재 탭의 검사 모듈이 준비됐다고 나와요. | 해당 페이지에서 확장이 실행된다는 뜻이에요. 그 사이트 주소가 활성 규칙에 들어 있어야 보호돼요. |
| 앱을 껐는데 웹에서 계속 막혀요. | 확장 창에서 **연결 해제**를 누르거나, 앱을 열어 중지 상태를 확장에 받아오세요. |
| 패턴을 추가한 뒤 저장이 안 돼요. | 목록의 빈 패턴을 채우거나 삭제해요. |
| 기록에 검사 한도 초과라고 나와요. | 글이 너무 길거나 검사량이 많아 확인을 끝내지 못한 경우에도 막을 수 있어요. 실제 토큰을 발견했다는 뜻은 아니에요. |
| 다시 켰더니 차단 기록이 없어요. | 차단 기록은 앱을 닫으면 지워져요. 저장한 규칙은 남아요. |
| 글자가 잘리거나 배율이 이상해요. | 실행 파일 옆의 **CreMore PasteGuard.exe.config** 파일이 있는지 확인하세요. |

### 앱 이름이나 웹사이트 주소를 직접 넣으려면?

- 앱은 `Slack.exe`처럼 **실행 파일명**을 넣어요. `C:\...` 같은 폴더 경로는 넣지 않아요.
- 웹사이트는 `notion.so`처럼 **도메인**을 넣어요. `https://`와 뒤쪽 페이지 주소는 빼요.
- 여러 개는 `Slack.exe, Notion.exe`처럼 **쉼표**로 나눠요.
- `*.example.com`은 `app.example.com` 같은 하위 주소를 뜻해요. 기본 주소까지 막으려면 `example.com, *.example.com`을 함께 넣어요.
- 특정 웹사이트만 막고 싶다면 `chrome.exe`를 앱 대상으로 넣지 마세요. 그렇게 하면 Chrome의 모든 탭이 앱 기준 대상이 돼요.

### 실행 폴더를 옮겨도 되나요?

네. **dist 안에 둘 필요는 없어요.** 앱을 닫고 `PasteGuard` 폴더 전체를 파일을 저장할 수 있는 위치로 옮기세요.

`CreMore PasteGuard.exe`, `CreMore PasteGuard.exe.config`, `extension`, `README.md`, `docs`를 함께 두세요. 기존 규칙을 유지하려면 **data 폴더도 함께** 옮겨요.

이미 확장을 등록했다면 새 위치의 `extension` 폴더를 브라우저에 다시 등록해 주세요. 다른 PC나 Windows 계정으로 옮기면 연결 키로 다시 연결해야 할 수 있어요.

### 새 버전으로 바꾸려면?

1. 앱을 닫고 기존 **data 폴더**를 따로 복사해 보관해요. 여기에 규칙과 연결 키가 있어요.
2. 앱 파일과 함께 받은 `extension` 폴더를 새 버전으로 바꿔요. 기존 `data`는 유지해요.
3. 브라우저의 확장 관리 화면에서 PasteGuard 확장을 새로고침해요. 폴더가 바뀌었다면 새 폴더를 등록해요.
4. 앱을 다시 열고 **보호 시작**을 눌러요.
5. 확장 창의 **정책 새로고침**을 누르고 대상 웹페이지도 새로고침해요.
6. 가짜 글자로 다시 시험해요.

여러 패턴을 쓰는 1.3.0부터는 **앱과 확장을 함께 업데이트**해야 해요. 앱만 바꾸면 이전 확장이 새 규칙을 읽지 못할 수 있어요. `data` 폴더나 연결 키는 다른 사람에게 보내거나 GitHub에 올리지 마세요.

## 보호 범위와 한계

**모든 비밀번호를 자동으로 알아내거나 모든 입력 방법을 막는 앱은 아니에요.** 저장한 글자 모양과 대상이 맞을 때, 지원하는 붙여넣기 방법을 막아요.

| 하는 일 | 하지 않는 일 |
|---|---|
| 지정한 Windows 앱의 `Ctrl+V`, `Shift+Insert` 검사 | Windows 앱의 우클릭 메뉴 붙여넣기 차단 |
| 확장이 준비된 웹페이지의 일반 붙여넣기 검사 | 글자를 하나씩 입력하기, 드래그, 파일 업로드 차단 |
| 정한 글자 모양과 비교 | 진짜 사용 가능한 토큰인지 확인하거나 Vault와 비교 |
| 최근 차단 기록 최대 200건 표시 | 모든 입력 경로의 유출을 막거나 영구 기록 보관 |

관리자 권한으로 실행한 앱이나 브라우저 내부 페이지 등에서는 보호를 보장하지 않아요. 준비가 끝나기 전에는 웹 검사가 작동하지 않을 수 있어요. [자세한 동작과 예외](docs/how-it-works.md)

검사는 이 PC에서 해요. 복사한 원문을 지우거나 외부 서버로 보내지 않아요. 차단 기록에도 원문을 남기지 않아요. [저장되는 정보 확인하기](docs/technical-reference.md#차단-기록과-저장-데이터)
